# Suraj Shaw — The Story So Far

A standalone personal website built with HTML, CSS, and JavaScript.

## Files

- `index.html`: biography, chapters, navigation, page title, and description.
- `styles.css`: colors, typography, responsive layouts, and motion preferences.
- `story.js`: chapter progress and scroll reveal effects.

## Preview

Open `index.html` in a web browser. No installation, build command, API keys, or login is required.

## GitHub and hosting

Place these files in the root of your chosen GitHub repository. Publish `index.html`, `styles.css`, and `story.js` together from the same directory using a static web host. If your host asks for a build command, none is needed. Use the repository root as its public directory.

Connect your domain through your hosting provider. The DNS records depend on that provider, so domain configuration is intentionally not included yet.

The site does not use ChatGPT, OpenAI APIs, a hosted database, a remote font service, analytics, or any external JavaScript library. Its only external visitor links point to Suraj's LinkedIn profile. The favicon is embedded in the HTML.

## Editing

Edit chapter text in `index.html`. Theme colors are defined at the top of `styles.css`. After changes, update the repository and publish through your chosen host.

This is the first narrative draft. Personalized portrait images and additional childhood anecdotes can be added later. Review the biography before making the site public.
